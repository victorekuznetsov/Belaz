# Каталог запасных частей БЕЛАЗ — публикуемая версия (Vercel)

Статический онлайн-каталог запчастей техники БЕЛАЗ, собранный из заводских
каталогов деталей (PDF) со сносками на техническую документацию.
Оформление и логика работы повторяют каталог Cummins (`Cummins_Parts_Book`),
схема сборки из PDF — каталог ESTAR (`ESTAR-Parts_Book`).
Фирменный стиль «Развитие», светлая и тёмная тема.

Это ветка каталога — только то, что нужно для публикации: страница каталога,
данные машин, чертежи и руководства. Все исходники — заводские каталоги,
руководства, прайсы, эксплуатационная статистика и скрипты сборки — в ветке
**`rawdata`**.

По вопросам работы каталога, ошибок и замечаний — Кузнецов В.Е.,
KuznetsovVE@industrservice.ru

## Что внутри

```
index.html · app.js · styles.css   оболочка каталога (статическая)
data/models.js                     реестр машин и подключённых документов
data/models/<id>.js                каталог машины: разделы, рисунки, детали
data/prices.js                     цены по четырём площадкам
data/fleet.js                      парк машин (78 ед.)
data/doctoc.js · data/xref.js      оглавления руководств и связка с каталогом
drawings/<id>/*.jpg                чертежи узлов
docs/                              руководства по эксплуатации и ремонту
brand/                             логотипы «Развитие» (свет/тёмная тема)
vercel.json                        конфигурация статического деплоя
```

## Возможности

- Переключатель машин; сквозной поиск сразу по всем каталогам — по
  **обозначению** БЕЛАЗ, по **коду ОКП** и по наименованию (рус./англ.).
- Чертёж рядом с перечнем позиций; номер на чертеже совпадает с номером
  позиции в таблице; у многолистовых узлов — перелистывание листов.
- Карточка детали: оба номера, кол-во на рисунке, признак взаимозаменяемости,
  цены по площадкам и «где применяется» по всем каталогам.
- **Цены четырьмя колонками** — ПК (Полюс Красноярск), ПА (Полюс Алдан),
  СЛ (Сухой Лог) и «Закупка» (самостоятельная закупка ЗЧ). Площадка для
  подсчёта заказа выбирается в шапке; цены можно перекрыть своим файлом.
- Заказ с выгрузкой в CSV и печатью, сохраняется в браузере.
- «Проверить список» — проверка своего перечня номеров на наличие в каталогах.
- Выгрузка всех номеров машины или всех каталогов в Excel (CSV).
- **Парк машин** — 78 единиц: поиск по гаражному и заводскому номеру,
  площадке, модели и двигателю с переходом в каталог нужной машины.
- **Документы** — руководства по эксплуатации и ремонту во встроенном
  просмотрщике с оглавлением по главам.

## Сноски на техническую документацию

Каждый раздел каталога 7513Т и 7513D связан с главой руководства: кнопка
«📖 Руководство по эксплуатации: гл. N» открывает документ сразу на нужной
странице. Связка строится автоматически (`data/xref.js`), оглавления
документов — из колонтитулов руководств (`data/doctoc.js`).

Руководство по поливооросительным машинам 76131/76135/7613D подключено к
каталогу целиком, без разбивки на главы: в этом документе нет колонтитулов
с номерами глав.

## Как это собрано

Скрипты сборки лежат в ветке `rawdata`, в папке `tools/`:

| Скрипт | Что делает |
|---|---|
| `parse_catalog.py` | каталоги самосвалов БЕЛАЗ (двуязычные, с кодом ОКП) |
| `parse_catalog_pshk.py` | каталог ПЩК-7547 (русский, без ОКП, другая вёрстка) |
| `parse_catalog_16m33.py` | каталог двигателя 16M33 (кит./англ., векторные чертежи) |
| `parse_prices.py` | четыре прайс-листа → `data/prices.js` |
| `parse_fleet.py` | выгрузка парка из SAP → реестр машин |
| `make_site_data.py` | реестр моделей, парк, перенос документов |
| `make_xref.py` | оглавления руководств и связка с разделами каталога |
| `optimize_drawings.py` | пережатие чертежей |

Разбор идёт по координатам колонок: страницы заводских каталогов свёрстаны
зеркально, поэтому границы колонок считаются от заголовка таблицы на каждой
странице. Чертежи БЕЛАЗ извлекаются из PDF как есть, чертежи 16M33 —
векторные, поэтому страница рендерится и обрезается по содержимому.
Одинаковые чертежи хранятся один раз (дедупликация по содержимому).

Разбор каталога 7513Т сверен с «Номерным указателем» самого каталога:
все 1 767 строк указателя нашлись в разобранных данных.

## Деплой на Vercel

Статический сайт, сборка не нужна. Vercel обслуживает файлы из корня
репозитория; `vercel.json` задаёт заголовки кеширования. Framework Preset:
**Other**, Build Command и Output Directory — пустые.

## Локально

Откройте `index.html` в браузере — каталог работает и по `file://`.
