# BELAZ — исходные материалы (ветка `rawdata`)

Это **ветка `rawdata`** репозитория каталога запасных частей БЕЛАЗ — «песочница»
с исходниками: заводские каталоги деталей, руководства по эксплуатации и ремонту,
прайс-листы, эксплуатационная статистика и технические отчёты. Ветка **не
деплоится**; публикуемый каталог собирается в ветке `main` (по образцу
репозиториев Cummins_Parts_Book и ESTAR-Parts_Book).

По вопросам — Кузнецов В.Е., KuznetsovVE@industrservice.ru
